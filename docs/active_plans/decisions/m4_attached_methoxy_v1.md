# M4 attached Methoxy V1 decision

## Status

Delivered on 2026-08-26 as one bounded extension of the reviewed attached
compact-group workflow. The active milestone authority remains
[compact_group_authoring_v1.md](../active/compact_group_authoring_v1.md).

## Decision

Ferrum supports attached `OMe` only. The immutable Rust catalog recipe is
neutral `R-O-CH3`: an attachment oxygen at the local origin, a neutral methyl
carbon at `(24, 0)`, and one normal single internal bond. The exterior bond
rewrites to the oxygen, which is the authoritative materialization focus.

The existing generic `AttachCompactGroupV1` transaction, candidate admission,
renderer preflight, session fence, PyO3 bridge, Qt chooser, materialization,
history, and reopen paths remain the only delivery route. The renderer owns
attached-pose normalization when a release is too close to the selected atom;
Qt supplies pointer intent and does not add a geometry exception. Free placement
remains `Me`-only.

## Evidence

The 2026-08-26 Graphify map places the delivery in the compact-group catalog,
attached-session, binding, and renderer communities. Current source review
confirms the recipe is admitted before ID reservation, materialization preserves
the exterior-bond identity and returns oxygen focus, and the generic PyO3/Qt
path projects Rust-owned choices without a second catalog.

Permanent evidence is semantic and local: Rust recipe/session coverage proves
the neutral O-C topology, rendered admitted candidate, refusal non-mutation,
materialization, history, and reopen; the binding test follows the Rust-issued
`methoxy` choice through generic attachment and materialization. The registered
public E2E authors the anchor through visible drawing, chooses `OMe`,
materializes it, and observes Molecule Report facts for `C3H8O`. Visual review
and fresh builds are implementation/release evidence, not pixel, timing, raw
CDML, or artifact-equivalence gates.

## Deferred work

This decision does not approve free `OMe`, a new CLI/protocol attachment route,
label parsing, runtime chemistry parsing, or a second frontend model.
Hydroxymethyl requires its own selected slice. Carbonyl recipes (`COOH`,
`COCl`) remain deferred pending a carbonyl-branch review. `CN` requires a
triple-bond model, and `Ph` requires an aromatic/resonance and depiction model.
